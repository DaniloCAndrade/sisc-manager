## 🛠️ Tecnologias

- **React 18** - Biblioteca UI
- **TypeScript** - Tipagem estática
- **Vite** - Build tool e dev server
- **Ant Design** - Componentes UI
- **TailwindCSS** - Estilização utilitária
- **Axios** - Requisições HTTP
- **React Router DOM** - Roteamento
- **Day.js** - Manipulação de datas
- **Framer Motion** - Animações

## 📦 Pré-requisitos

- Node.js **18+** ou **20+**
- npm ou yarn ou pnpm
- Backend da aplicação rodando (porta 3001)

## 🔧 Instalação

```bash
# Clone o repositório
git clone https://github.com/very-tech/sisc/front-sisc.git
git clone git@gitlab.com:very-tech/sisc/front-sisc.git

# Acesse o diretório
cd frontend

# Instale as dependências
npm install

# ou
yarn install

# ou
pnpm install
